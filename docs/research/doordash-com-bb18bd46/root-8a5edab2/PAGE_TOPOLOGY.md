# Page topology

Visual order:
1. Sticky black header (overlay after scroll > 48px)
2. Hero 650px red with food collage background, logo, H1, address search
3. Black audience cards (Dasher / Merchant / App)
4. White promo strip ($0 delivery fee)
5. Alternating feature splits (restaurants, DashPass, grocery, convenience, beauty, flowers, alcohol, pets, dasher, partner)
6. Neighborhood tabs (cities / cuisines / chains)
7. Footer popular categories + company links
8. Auth modal overlay (click Sign In / Sign Up)
9. Store feed view after address submit: header search, category rail, restaurant cards

Interaction:
- Hero address is click-driven autocomplete then view switch
- Neighborhood tabs are click-driven
- Header appearance is scroll-driven
- Auth modal is click-driven
