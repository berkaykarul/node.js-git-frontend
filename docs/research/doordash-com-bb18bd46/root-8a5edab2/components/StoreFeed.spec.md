# StoreFeed Specification

## Overview
- **Target files:** StoreFeed.tsx, CategoryRail.tsx, RestaurantCard.tsx
- **Interaction model:** click-driven filters + search (live site requires a selected address; clone uses mock SF restaurants)

## Layout
- Sticky white header: menu, logo, address pill (#f3f3f3), Search YemekYol pill, Sign In, cart
- Horizontal category chips 56px circles
- Restaurant cards: 16/10 image, rounded-2xl, name, star rating, cuisine, eta • distance • fee, DashPass badge, promo chip
