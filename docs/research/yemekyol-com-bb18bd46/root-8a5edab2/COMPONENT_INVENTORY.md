# YemekYol component inventory

- `HeroSection`: auth links, wordmark, offer heading, address form, utility location actions.
- `PartnerBand`: three black-background promotional cards with image/icon placeholder, description, and CTA.
- `OfferNotice`: inline wordmark, first-order message, See all link.
- `FeatureArticle`: reusable image/text story with optional eyebrow, disclaimer, and alternating desktop order.
- `NeighborhoodSection`: click-driven tab list and responsive item grid.
- `SiteFooter`: category grid, grouped link columns, legal brand row.

All components are scoped to `src/components/sites/yemekyol-com-bb18bd46/root-8a5edab2/`.
