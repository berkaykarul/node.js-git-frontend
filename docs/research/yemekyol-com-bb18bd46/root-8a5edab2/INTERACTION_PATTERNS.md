# YemekYol interaction patterns

- Auth and CTA controls are pill-shaped links/buttons with 150ms transitions.
- Address form is a submit interaction; this clone shows a short status message after submission.
- Current-location action uses the browser geolocation API when available and updates the input with a readable location label.
- Neighborhood tabs switch visible lists without navigation.
- Text links underline on hover; active tabs use a 2px black bottom border.
- No scroll-based behavior, sticky navigation, modal, carousel, or autoplay was observed.
